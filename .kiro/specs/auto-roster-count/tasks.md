# План реализации: auto-roster-count

## Обзор

Добавление колонки «Авт» (автосоставы) на страницу `/mng_asktoplay.php` в Tampermonkey-скрипте `calc.user.js`. Реализация включает определение сезона, парсинг HTML `roster_m.php`, параллельную загрузку данных и интеграцию в существующую функцию `enhanceAskToPlayPage()` по аналогии с колонкой «Шк».

## Примечания

- Задачи с `*` являются опциональными и могут быть пропущены для ускорения MVP
- Каждая задача ссылается на конкретные требования для трассируемости
- Контрольные точки обеспечивают инкрементальную валидацию
- Реализация ведётся в единственном файле `calc.user.js` (Tampermonkey userscript)
- Новые функции размещаются рядом с аналогичными (`fetchTeamSchool`, `detectSchool`)
- Интеграция в `enhanceAskToPlayPage()` выполняется по аналогии с существующей колонкой «Шк»
