# Документ требований

## Введение

Доработка Tampermonkey-скрипта `calc.user.js`: добавление на страницу `/mng_asktoplay.php` новой колонки «Авт» (автосоставы). Колонка показывает количество матчей, в которых менеджер команды не отправил состав (автосостав). Данные получаются путём загрузки страницы `roster_m.php?filter=1` для каждой команды и подсчёта символов `*` в колонке «А».

## Глоссарий

- **Скрипт**: Tampermonkey userscript `calc.user.js`
- **Страница_приглашений**: страница `/mng_asktoplay.php`, на которой отображается список команд для приглашения на матч
- **Парсер**: функция `parseAutoRosterCount`, разбирающая HTML-ответ `roster_m.php` и подсчитывающая автосоставы
- **Загрузчик**: функция `fetchAutoRosterCount`, выполняющая HTTP-запрос к `roster_m.php` и вызывающая Парсер
- **Определитель_сезона**: функция `getCurrentSeason`, извлекающая номер текущего сезона из DOM страницы
- **Таблица_матчей**: HTML-таблица с классом `tbl` на странице `roster_m.php?filter=1`, содержащая список матчей команды
- **Колонка_А**: колонка в Таблице_матчей с заголовком «А», где `*` означает автосостав
- **Автосостав**: матч, в котором менеджер не отправил состав; обозначается символом `*` в Колонке_А

## Требования

### Требование 1: Определение текущего сезона

**Пользовательская история:** Как скрипт, я хочу определить номер текущего сезона из страницы, чтобы сформировать корректный URL для загрузки данных.

#### Критерии приёмки

1. WHEN Страница_приглашений загружена, THE Определитель_сезона SHALL извлечь номер сезона из ссылок на `roster_m.php`, содержащих параметр `season=`
2. IF ссылки с параметром `season=` отсутствуют, THEN THE Определитель_сезона SHALL попытаться извлечь номер сезона из текста страницы по шаблону «Сезон N»
3. IF номер сезона не удалось определить ни одним способом, THEN THE Определитель_сезона SHALL вернуть `null`

### Требование 2: Парсинг автосоставов из HTML

**Пользовательская история:** Как скрипт, я хочу корректно парсить HTML-страницу `roster_m.php` и подсчитывать автосоставы, чтобы отображать точное число в колонке «Авт».

#### Критерии приёмки

1. WHEN Парсер получает валидный HTML с Таблицей_матчей, THE Парсер SHALL найти индекс Колонки_А в строке заголовка таблицы (`tr[bgcolor="#006600"]`)
2. WHEN индекс Колонки_А найден, THE Парсер SHALL подсчитать количество строк данных, в которых ячейка с этим индексом содержит ровно символ `*`
3. WHEN Парсер получает валидный HTML с Таблицей_матчей, THE Парсер SHALL возвращать целое число, равное количеству автосоставов
4. IF HTML не содержит Таблицу_матчей (элемент `table.tbl`), THEN THE Парсер SHALL вернуть 0
5. IF Таблица_матчей не содержит Колонку_А в заголовке, THEN THE Парсер SHALL вернуть 0
6. IF HTML является пустой строкой или невалидным документом, THEN THE Парсер SHALL вернуть 0
7. THE Парсер SHALL возвращать значение типа число, большее или равное 0, для любого входного HTML

### Требование 3: Загрузка данных автосоставов

**Пользовательская история:** Как скрипт, я хочу загружать страницу `roster_m.php?filter=1` для каждой команды и получать количество автосоставов, чтобы заполнить колонку «Авт».

#### Критерии приёмки

1. WHEN Загрузчик вызван с идентификатором команды и номером сезона, THE Загрузчик SHALL выполнить HTTP-запрос к URL `{BASE_URL}/roster_m.php?num={teamId}&season={season}&filter=1`
2. WHEN HTTP-запрос завершён успешно, THE Загрузчик SHALL передать полученный HTML в Парсер и вернуть результат через callback
3. IF HTTP-запрос завершился ошибкой или вернул пустой ответ, THEN THE Загрузчик SHALL вызвать callback со значением 0
4. THE Загрузчик SHALL вызвать callback ровно один раз для каждого вызова

### Требование 4: Добавление колонки «Авт» в таблицу

**Пользовательская история:** Как пользователь, я хочу видеть колонку «Авт» в таблице команд на странице приглашений, чтобы знать, у каких команд были автосоставы.

#### Критерии приёмки

1. WHEN Страница_приглашений загружена и сезон определён, THE Скрипт SHALL добавить заголовок «Авт» в строку заголовков таблицы рядом с колонкой «Шк»
2. WHEN заголовок «Авт» добавлен, THE Скрипт SHALL создать ячейку с текстом «...» для каждой строки команды (`tr_send_{teamId}`)
3. WHEN данные автосоставов загружены для команды, THE Скрипт SHALL заменить текст «...» в ячейке на числовое значение количества автосоставов
4. WHEN количество автосоставов больше 0, THE Скрипт SHALL подсветить ячейку фоновым цветом `#ffe0e0` и добавить всплывающую подсказку с текстом «Автосоставов: N»
5. IF сезон не удалось определить (Определитель_сезона вернул `null`), THEN THE Скрипт SHALL пропустить добавление колонки «Авт» и продолжить работу без неё

### Требование 5: Параллельная загрузка с ограничением

**Пользовательская история:** Как пользователь, я хочу, чтобы данные загружались быстро, но без перегрузки сервера, чтобы страница оставалась отзывчивой.

#### Критерии приёмки

1. WHILE выполняется загрузка данных автосоставов, THE Скрипт SHALL поддерживать не более MAX_PARALLEL (3) одновременных HTTP-запросов
2. WHEN один HTTP-запрос завершён, THE Скрипт SHALL запустить следующий запрос из очереди, если очередь не пуста
3. THE Скрипт SHALL обработать все команды в очереди до завершения работы, заменив все ячейки «...» на числовые значения

### Требование 6: Защита от повторного добавления

**Пользовательская история:** Как пользователь, я хочу, чтобы колонка «Авт» не дублировалась при повторном срабатывании скрипта.

#### Критерии приёмки

1. WHEN Скрипт обнаруживает существующий элемент с классом `auto-roster-header` в таблице, THE Скрипт SHALL пропустить добавление колонки «Авт»
